# CodeFlow: AI-Powered Visual Code Understanding

CodeFlow transforms complex code into interactive flowcharts instantly using Claude AI and real-time streaming. Developers waste hours trying to understand unfamiliar codebases - CodeFlow solves this by visualizing control flow, decision points, and complexity metrics in seconds. What makes it unique is the streaming AI analysis that shows you the flowchart being built in real-time, combined with interactive ReactFlow visualizations that let you explore code structure visually. It's technically impressive because it seamlessly integrates Claude's code analysis capabilities with a production-ready Next.js app, automatic flowchart layout algorithms, and multi-language support - all wrapped in a polished, accessible UI built with shadcn/ui that makes code review, learning, and documentation dramatically more efficient.
